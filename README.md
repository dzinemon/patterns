## 🧩 Patterns Included

This repository showcases various React patterns including:

- [Representational Component](https://reactjs-patterns.netlify.app/patterns/representational) - Components that focus on rendering UI without managing state
- [Compound Component](https://reactjs-patterns.netlify.app/patterns/compound) - Components that work together to form a cohesive UI pattern
- [Higher Order Component](https://reactjs-patterns.netlify.app/patterns/hoc) - Functions that take a component and return a new enhanced component
- [Render Props](https://reactjs-patterns.netlify.app/patterns/render-props) - Sharing code between components using props whose value is a function
- [Controlled Component](https://reactjs-patterns.netlify.app/patterns/controlled) - Components where form data is handled by React component state
- [Uncontrolled Component](https://reactjs-patterns.netlify.app/patterns/uncontrolled) - Components that maintain their own internal state using refs
- [Context API](https://reactjs-patterns.netlify.app/patterns/context-api) - Sharing state across components without prop drilling
- [Hooks](https://reactjs-patterns.netlify.app/patterns/hooks) - Functions that let you use state and lifecycle features in functional components
- [Custom Hooks](https://reactjs-patterns.netlify.app/patterns/custom-hooks) - Extracting component logic into reusable functions
- [Portals](https://reactjs-patterns.netlify.app/patterns/portals) - Rendering elements outside the React DOM hierarchy
- [Lazy Loading](https://reactjs-patterns.netlify.app/patterns/lazy-loading) - Loading components only when they are needed
- [Error Boundaries](https://reactjs-patterns.netlify.app/patterns/error-boundaries) - Catching JavaScript errors in UI components
